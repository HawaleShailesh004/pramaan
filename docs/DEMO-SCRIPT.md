# Pramaan demo script (120 seconds)

## Setup (before camera)

```bash
cd pramaan
npm run setup
npm run api    # :8790
npm run web    # :5175
```

Open `#demo` for one-click cast, or follow beats below manually.

---

## Beats

| Time | Beat | Screen | Say |
| --- | --- | --- | --- |
| 0–15s | Problem | `#` home | “Placement week. Forty marksheets — or one predicate per policy. DigiLocker opens the **file**. We prove a **fact**.” |
| 15–35s | Issuer | `#issuer` | “USAR imports CSV — hashes only. Meera 7.4, Kabir 6.2, Arya 8.1. No PDF on chain.” Click **Import & publish**. |
| 35–55s | Cutoff 7.0 | `#recruiter` | “The slider **is** the product.” Set **7.0**. Prove Meera → gold. Prove Kabir → FailWell below cutoff. |
| 55–70s | Cutoff 8.0 | `#recruiter` | Move slider to **8.0**. Meera fails. Arya passes. “Same leaf. Different question.” |
| 70–85s | Revoke | `#issuer` | **Revoke Kabir**. Back to recruiter — Kabir cannot prove even at 6.0. |
| 85–95s | Fake uni | `#fake` | “Letterhead is not a root.” Prove 9.9 → fails membership. |
| 95–110s | Explorer | `#explorer` | “Ledger shows counts and policy hashes — never CGPA.” |
| 110–120s | Midnight | README | Contract address on PreProd. “Policy hash bound in the proof.” |

## FailWell lines (do not skip)

- **Below cutoff:** “The leaf is real. The bar moved.”
- **Revoked:** “Registrar corrected the award.”
- **Fake issuer:** “Letterhead is not a root.”
