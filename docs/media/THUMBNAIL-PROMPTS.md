# Devpost thumbnail - emotional prompts (3:2)

**Goal:** Judges should feel placement-week pressure - and see the cutoff instrument - before a feature list.

**Hard rules (keep every prompt):**

- No identifiable faces in sharp focus (hands / over-shoulder / soft blur OK)
- No trauma porn, crying close-ups, or “broke student” stereotypes
- Synthetic placement mood - fairness + dignity, not crypto flex
- Exact **3:2** (e.g. 3000×2000). Sharp title text.
- Palette: ink `#0b0c10`, gold `#e8c547`, fog slate, forest public rail `#0e2a24` - **no purple neon**

**Global negative (append to all):**

```
sharp identifiable face, celebrity lookalike, purple neon, cyberpunk HUD, crypto coins, DigiLocker logo copy, blurry text, misspelled words, watermark, logo salad, crowded collage, cream terracotta AI default
```
